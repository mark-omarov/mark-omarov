# omarov.dev

My personal site. Next.js, Tailwind, a markdown blog, and pixel art drawn
entirely in code.

```bash
pnpm install
pnpm dev
```

- **Places:** every scene on the home page is code that draws into a tiny
  framebuffer. Click around; a few things hide easter eggs.
- **Blog:** a digital garden with wikilinks, backlinks and notes that grow
  from seedling to evergreen. Posts live in `content/blog/`.
- **Vim keys:** the whole site works from the keyboard. Press `?`.
